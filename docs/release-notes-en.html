octave-calc 0.1.0

The first release.

  • Data > Statistics with GNU Octave: one dialog holding forty-six analyses in four categories, group comparisons, distribution fitting, random numbers and experimental design, and a fifth category that runs one of your own Octave functions the same way.
  • The spreadsheet functions OCTAVE and OCTRANGE.
  • Every call runs in a devtools server, sandboxed where the machine allows it. Formulas need the sandbox; the menu does not, so the menu works on Windows, where there is no sandbox yet.

Needs GNU Octave with the devtools and statistics packages. Tested on LibreOffice 25.2 on Linux; it declares 7.4 as its minimum and has not been run below 25.2.
