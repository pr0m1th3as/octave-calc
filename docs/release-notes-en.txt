octave-calc 0.1.0

The first release.

  * Data > Statistics with GNU Octave: one dialog holding forty-six
    analyses in four categories, group comparisons, distribution fitting,
    random numbers and experimental design, and a fifth category that runs
    one of your own Octave functions the same way.

  * The spreadsheet functions OCTAVE and OCTRANGE, which call an Octave
    function on the cells of your sheet from a formula.

  * Every call runs in a devtools server, sandboxed where the machine
    allows it.  Formulas need the sandbox; the menu does not, so the menu
    should work on Windows, which has no sandbox yet.  That has not been
    run, and neither has macOS; please say what you find.

Needs GNU Octave with the devtools and statistics packages installed.

Tested on LibreOffice 25.2 on Linux only.  It declares 7.4 as its
minimum and has not been run below 25.2.
